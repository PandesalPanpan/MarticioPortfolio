# Brand assets

The PM ligature: the P and the M share a single vertical stem.

Generated by `node scripts/build-brand-assets.mjs` from the coordinates in
`src/components/Monogram.tsx`. Edit the mark there, rerun the script, commit
the result. Do not hand-edit these files.

## Which file to use

| File | Use for |
| --- | --- |
| `pm-mark-dark.svg` | The mark on its own, on light backgrounds. Default choice. |
| `pm-mark-light.svg` | The mark on its own, on dark backgrounds. |
| `pm-icon-dark.svg` | Where a container helps it hold its own: avatars, app tiles, favicons. |
| `pm-icon-light.svg` | Same, inverted. |

PNGs are exported alongside each SVG. **Prefer the SVG** anywhere it is
accepted; it stays sharp at any size. Reach for a PNG only where SVG is
rejected, which in practice means GitHub/LinkedIn avatars and some print
tools.

Sizes: marks at 256/512/1024, icons at 16/32/64/128/256/512/1024. All PNGs
have a transparent background.

## Sizing

The mark is legible down to about 32px. Below that the two letters start to
merge into a single shape, so at 16px prefer the boxed icon, which at least
keeps a recognisable silhouette.

## Colours

Monochrome by design, matching the site.

- Ink `#17171A`
- Paper `#FAF9F7`

Recolouring to a single flat colour is fine. Do not add gradients, outlines,
or a second colour, and do not stretch the mark: the shared stem is the whole
idea and it only reads at the drawn proportions.
